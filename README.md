A web-based research tool designed to help INCEIF's researchers, academics, and students discover relevant Islamic finance journals through keyword-based searching.

The platform provides journal information, including rankings (Scopus Quartile, Web of Science, ABDC and MyCite), publisher details, journal links, and VOSviewer keyword co-occurrence visualization to explore research trends and topics.

Features:

Keyword-based journal discovery
Journal ranking information (Quartile, WoS, ABDC)
Direct links to journal websites
VOSviewer keyword co-occurrence visualization
Expanding database of Islamic finance journals

This project is a work in progress, with more journals and features planned for future updates.
